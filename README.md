# FreelanceHub

FreelanceHub is a mobile freelancing platform designed to connect clients and freelancers through a simple and responsive mobile experience.

The application allows users to create profiles, browse and publish freelance gigs, communicate through chat, and manage interactions between service providers and clients.

## Features

- User registration and authentication
- Freelancer and client profiles
- Create and browse freelance gigs
- User profile management
- Real-time or in-app messaging between users
- File/image upload support
- Mobile-friendly navigation and interface
- Backend API integration
- Persistent data storage

### Database
- **MongoDB**

## Architecture

The project follows a client-server architecture:

- The **Ionic/Angular mobile application** handles the user interface and mobile experience.
- The **Flask backend** manages business logic and API requests.
- **MongoDB** is used for storing application data such as users, profiles, gigs, and related information.

## Main Functionalities

### Freelance Gigs

Users can create and browse freelance service offers, making it easier for clients to discover available services.

### User Profiles

Users can maintain personal profiles containing relevant information for the freelancing platform.

### Messaging

The platform includes chat functionality to allow freelancers and clients to communicate directly.

### Uploads

Users can upload files or images related to their profiles or platform interactions.

## Project Purpose

FreelanceHub was developed as a mobile development project to explore the design and implementation of a full-stack mobile application combining a hybrid mobile frontend with a Python backend and NoSQL database.
